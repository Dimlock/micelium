# Как заменить демонстрационные компоненты

Все компоненты собраны в **`data/components.json`**. Сделайте резервную копию файла перед редактированием. JSON должен оставаться в UTF-8, без комментариев и висячих запятых.

После изменения файла начните новую партию. Старые сохранения ссылаются на ID компонентов: если удалить или переименовать использованные ID, старое сохранение может оказаться несовместимым.

## 1. Общие поля

```json
"meta": {
  "title": "Мой проверенный набор",
  "is_placeholder": false,
  "warning": "..."
}
```

- `is_placeholder`: информационный флаг. Демо-карты также имеют `"placeholder": true` и получают значок «ДЕМО».
- `colors`: словарь русских названий цветов.
- `cards`: обычные карты грибов.
- `tiles`: треугольные тайлы.
- `automa`: карты автомы.

## 2. Карта гриба

```json
{
  "id": "boletus_01",
  "name": "Белый гриб",
  "latin": "Boletus edulis",
  "placeholder": false,
  "points": 2,
  "cost": ["red", "red"],
  "spores": 3,
  "effect_type": "mushroom",
  "effect_id": "mushroom_spores_plus1",
  "effect_text": "Этот гриб развеивает на 1 спору больше.",
  "art": "res://assets/cards/boletus_01.png"
}
```

Обязательные для логики поля:

| Поле | Значение |
|---|---|
| `id` | Уникальная строка; не повторять ID карт автомы |
| `points` | Целые победные очки |
| `cost` | Массив цветов тайлов: `red`, `green`, `brown`, `yellow`; чёрный тайл при оплате универсален |
| `spores` | Сколько спор развеивает гриб до бонусов |
| `effect_type` | `instant`, `persistent` или `mushroom` |
| `effect_id` | Идентификатор из таблицы в README |
| `effect_text` | Текст на карте/в подсказке |

`name`, `latin`, `placeholder`, `art` предназначены для отображения и метаданных. В текущем прототипе рендер векторный; путь `art` является резервом для подключения оригинальных иллюстраций в `card_view.gd`/`board_view.gd`, а не обещанием автоматической обрезки арта по треугольной маске.

### Если нужного эффекта нет

Оставьте уникальный `effect_id`, например `"move_edge_tile"`. Карта и остальные правила продолжат работать, а при разложении журнал честно покажет `ЗАГЛУШКА: эффект … не автоматизирован`. Для полной автоматизации добавьте обработчик в `_apply_decomposition_effect()` в `scripts/game_state.gd` и, если нужен выбор цели, соответствующий режим в `scripts/main.gd`.

## 3. Тайл

```json
{
  "id": "tile_01",
  "color": "green",
  "insect": true,
  "rotation": 0,
  "placeholder": false,
  "art": "res://assets/tiles/tile_01.png"
}
```

- `color`: `red`, `green`, `brown`, `yellow` или `black`.
- `insect`: кладётся ли жетон при появлении тайла, если общий запас ещё не пуст.
- `rotation`: 0–2; циклически сопоставляет стороны тайла направлениям O/U/A.
- `id`: уникальный ID физического тайла.

В комплекте по правилам: 44 цветных тайла (по 11) и 6 чёрных. В одиночной игре с автомой чёрные исключаются автоматически.

> Точное распределение насекомых и ориентация символов настоящих тайлов не восстанавливались по миниатюрам PDF. Заполните эти поля по своим компонентам.

## 4. Карта автомы

```json
{
  "id": "automa_01",
  "name": "Автома 01",
  "placeholder": false,
  "cost": ["red", "any"],
  "spores_medium": 2,
  "spores_hard": 3,
  "effect_type": "persistent",
  "effect_id": "queen_spores_3",
  "effect_text": "...",
  "move_target": "opponent_mushroom"
}
```

- В `cost` допускается `any`: спора с тайла любого цвета.
- `spores_medium`/`spores_hard`: число спор для двух уровней сложности.
- `move_target`: `opponent_mushroom`, `own_mushroom`, `opponent_queen`, `opponent_spores`, `insect`.
- Эффекты используют ту же систему `effect_id`. Эффекты, требующие обычной руки, для автомы могут быть неприменимы; не назначайте их без дополнительной обработки.

Автома получает 5 очков за каждый выращенный гриб и не получает жетон конца игры, как указано в правилах.

## 5. Изображения

Сейчас `assets/card_placeholder.svg` и `assets/tile_placeholder.svg` специально нейтральные. Можно создать:

```text
assets/cards/...
assets/tiles/...
assets/automa/...
```

Для полноценного показа своего арта рекомендуется:

1. Для карт — загрузить `Texture2D` в `MyceliumCard.setup()` и рисовать его вместо `_draw_mushroom()`.
2. Для тайлов — заменить/дополнить `_draw_tile()` в `MyceliumBoard`, применив треугольную маску или подготовленные заранее треугольные PNG с прозрачностью.
3. Оставить поверх арта игровые фишки, споры, символы типа и подсветку — они рисуются отдельно.

Такое разделение позволяет сначала внести точные данные и проверить партию на заглушках, а художественный слой подключить позже.
